# V-Bucks Store — Telegram Mini App (макет)

Статический прототип магазина подарочных карт Epic Games (V-Bucks) для Telegram Mini App.
Без сборки и зависимостей — чистый HTML/CSS/JS.

## Структура

```
index.html          все экраны + SVG-иконки
css/style.css       тёмно-зелёная тема
js/app.js           логика: экраны, каталог, рулетка, призы
assets/             логотип, монета, favicon (SVG)
```

## Экраны

| Экран | Что делает |
|---|---|
| Загрузка | прогресс-бар со сменой подписей, ~1.8 с |
| Главная | герой-блок, кнопка «Получить подарочную карту», «Мои призы», «Поддержка» |
| Каталог | 4 номинала V-Bucks: 1 000 / 2 800 / 5 000 / 13 500 |
| Оформление | выбор региона (6 шт.), ник Epic Games с валидацией, итог со скидкой |
| Успех | номер заказа и сводка |
| Мои призы | выигранные скидки и V-Bucks (хранятся в `localStorage`) |
| Рулетка | горизонтальная лента внизу главной, прокруток неограниченно |
| Лента отзывов | бесконечная вертикальная прокрутка, счётчики «онлайн» и «заказов» живут сами |

## Запуск локально

Нужен любой статический сервер. Например, Python:

```bash
python -m http.server 8080
```

Открыть `http://localhost:8080`. Вне Telegram всё работает — SDK подключается опционально.

## Подключение к боту

1. Залить папку на HTTPS-хостинг (GitHub Pages, Vercel, Netlify, Cloudflare Pages).
   Домен обязательно **https** — Telegram не откроет http.
2. В [@BotFather](https://t.me/BotFather): `/newapp` → выбрать бота → указать URL.
3. Либо кнопкой в самом боте:

```python
from telegram import InlineKeyboardButton, InlineKeyboardMarkup, WebAppInfo

kb = InlineKeyboardMarkup([[
    InlineKeyboardButton("Открыть магазин", web_app=WebAppInfo(url="https://ваш-домен"))
]])
await update.message.reply_text("Магазин V-Bucks:", reply_markup=kb)
```

## Что макет НЕ делает

- нет оплаты и бэкенда — кнопка «Оформить заказ» просто рисует экран успеха;
- заказы никуда не отправляются, призы лежат только в браузере пользователя;
- цены и статистика («12 480 заказов») — заглушки.

## Что менять под себя

| Что | Где |
|---|---|
| Номиналы и цены | `PACKS` в `js/app.js` |
| Регионы | `REGIONS` в `js/app.js` |
| Призы и их шансы (`w` — вес) | `PRIZES` в `js/app.js` |
| Цвета | CSS-переменные в начале `css/style.css` |
| Скорость рулетки | `transform 4.6s` в функции `setX` |
| Тексты отзывов | `REVIEWS` в `js/app.js` |
| Скорость ленты отзывов | `FEED_SPEED` (px в секунду) в `js/app.js` |

## Заметки по реализации

- Флаги стран нарисованы кодом (`RU`, `TR`, …), а не эмодзи: 🇷🇺 не отображается
  в Telegram Desktop на Windows.
- Рулетка — лента из 12 повторов призов. После остановки она незаметно
  «перематывается» на такой же слот ближе к началу, поэтому крутить можно бесконечно.
- Лента отзывов заполняет свободное место (`flex:1`): на высоком экране показывает
  8–9 отзывов, на низком сжимается до одного и продолжает ползти.
- `transitionend` всплывает, поэтому обработчик конца прокрутки проверяет
  `e.target === trackEl && e.propertyName === 'transform'`. Без этой проверки
  событие от слота (снятие подсветки победителя) обрывало вторую прокрутку через 0.3 с.
- Ник валидируется как `^[A-Za-z0-9._-]{3,16}$` — кириллица не проходит.
- Пароль от Epic Games не запрашивается нигде и не должен запрашиваться:
  для доставки подарочной карты достаточно ника.
